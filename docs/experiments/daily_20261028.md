# 2026-10-28：坐标与动作语义契约

## 目标

完成 D3 的坐标/动作语义切片，避免 CARLA、AirSim 和机体控制量在接入时被隐式混用。

## 代码交付

新增 `src/jev_uav_track/frames.py`：

- `ENU`：世界坐标 `x=east, y=north, z=up`。
- `NED`：世界坐标 `x=north, y=east, z=down`。
- `BODY_FLU`：机体坐标 `x=forward, y=left, z=up`。
- ENU/NED 之间可逆转换；BODY_FLU 与世界坐标转换必须显式提供 yaw，缺少 yaw 会拒绝。

`SimAction` 现在带 `command_frame`，默认是 `body_flu`，未知坐标系在构造时拒绝。该契约只做纯数学转换和输入校验，不启动仿真器、不修改端口或控制器。

## 验收

```powershell
python -m pytest -q
python -m compileall -q scripts src
```

结果：`46 passed`，编译检查通过。覆盖 ENU↔NED 可逆性、BODY_FLU yaw 旋转、缺少 yaw 和未知动作坐标系等边界。

## 限制与下一步

这些是仓库内部的明确约定，尚未证明 CarlaAir 发行版的实际地图轴与 AirSim 配置完全采用同一约定；D2 的独立实例所有权仍未核验。接入 adapter 时必须读取实际配置并记录转换矩阵，不能把本模块的默认值当成真实仿真证据。下一步进入 D4：在固定时域和动作语义下补跨 episode rollout 支持域、动作覆盖和 residual 校准报告。
