## 当日续作：时域契约贯穿推理与 residual 重训

复核发现前一版只保存了解析时域，没有让 learned 推理实际采用它。比如 3 帧 × 0.2 秒训练出来的模型仍会搭配默认 1 秒候选。这次 learned rollout 从单 episode 或跨 episode 的模型 summary 读取时域，自动配置透明 baseline；显式传入不匹配的 baseline 会拒绝。旧模型文件仍可加载和查看，但缺失时域 provenance 时不允许 rollout 推理，需重训，不猜测旧 residual 标签所用的 baseline 时域。

同时修正非整数步长时轨迹终点可能早于预测时域的问题；训练会拒绝非有限值、重复/倒退时间戳、明显不均匀的未来跨度，以及直接拼接不同时域 episode。检查覆盖全部时间窗口，不能靠 stride 跳过坏帧。

验收：53 个测试通过，compileall 与 diff 检查通过。新增回归包含 0.6 秒模型保存/重载后动作时长与终点、错误 baseline、旧模型拒绝、坏时间戳和混合时域。

重训命令（只读 PASS HDF5，无外部 API 调用）：

```powershell
python scripts/compare_recorded_rollouts.py --split artifacts/experiment_split_20261026.json --output artifacts/aligned_rollout_20261028 --samples-per-episode 24
```

固定 6 train / 6 validation，每 episode 24 个样本，分别 144 个训练/验证样本；显式检查 1 秒时域。两个模型保存并重载后确认推理时域约为 0.99999998 秒。完整 JSON 和 NPZ 保存在上述本机 artifacts 目录；脚本随仓库提交。

| 记录动作后果预测 | validation 距离误差 RMSE |
| --- | ---: |
| 透明 rollout | 0.242190 m |
| absolute ridge | 0.874749 m |
| baseline residual ridge | 0.173565 m |

透明误差来自 residual 标签（真实 future outcome 减 baseline）的 RMS；residual 模型的预测残差误差与重建后 outcome 误差等价。因此三者在同一批记录动作、未来标签、时间跨度下可比较。residual 相对透明距离 RMSE 下降约 28.3%，不是跟踪成功率提升；没有置信区间，尚不构成泛化收益结论。

此处使用 HDF5 真值状态和记录 camera velocity，仍属于 oracle-state 离线校准。validation 全可见，absolute visibility RMSE 为零只是常量标签，不代表遮挡预测能力。未执行候选反事实动作、未评估 final test，也未调用真实 Jev。身份交叉依然 NOT_AUDITED。
