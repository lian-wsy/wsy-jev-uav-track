# CarlaAir 小规模离线实验记录

日期：2026-10-22

本次实验只读一份已经通过校验的 trimmed episode：

```text
Town05_bicycle_frequent_turns_close_seed26094435.hdf5
schema=carlaair_uav_v2_candidate
validation_status=PASS
frame_count=300
```

适配器以状态模式打开文件，没有加载 RGB，也没有写入源 HDF5。训练和评估使用 CarlaAir 环境中的 NumPy/h5py；Jev 端使用仓库内的 `MockJevClient`，因此没有发起网络请求，也没有使用或暴露 API key。生成的 `.npz` 和 JSON 位于本地 `artifacts/small_experiment/`，该目录被 Git 忽略。

## 训练

命令参数为 `horizon_frames=5`、`stride=2`、`max_samples=128`，按时间顺序切分为 90 个训练样本和 38 个 holdout 样本。

| 输出 | 训练 RMSE | holdout RMSE |
| --- | ---: | ---: |
| visibility probability | 0.000 | 0.000 |
| image center error | 0.000 | 0.000 |
| range error (m) | 0.452 | 0.995 |
| covariance trace | 约 0 | 约 0 |

这个 episode 的可见性和遮挡标签几乎没有变化，因此可见率和协方差误差不能代表泛化能力。当前训练器把观测到的相机速度作为动作特征，是 outcome 校准基线，不是反事实动力学模型。

## 离线 Jev 评估

评估取 32 帧、步长为 5，候选动作仍经过安全过滤。结果为：

```text
backend=MockJevClient
evaluated_frames=32
safe_action_rate=1.0
fallback_rate=1.0
mean_oracle_regret=0.0
mean_actual_visibility=1.0
mean_actual_range_m=11.013
choice_counts={climb: 32}
```

Mock Jev 在这条单一 episode 上的最高概率约为 0.156，低于生产选择器的置信度门槛，所以每帧都记录了 `confidence_gate` 并使用确定性安全 fallback。这个结果验证了适配器、belief、rollout、门控和审计报告能够串起来运行，不代表真实 Jev 的决策质量。接入真实 Jev 或覆盖更多状态后，应继续报告非 fallback 选择率、身份保持率、重捕获时间和闭环安全事件。
