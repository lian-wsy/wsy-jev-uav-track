# D4：跨 episode rollout 与动作支持域（2026-10-29）

## 冻结设置

用户明确推进D4，D1–D3遗留的独立town/test与Jev对账不改记通过。本实验沿用39集development split v2，只读取28 train与6 validation；5 development_stress不读取，未创建或使用final test。仿真、外部采集/上传和真实Jev均不调用。

每episode按现有采样器在stride=2的有效起点中等距选96个；horizon_frames=5，要求实际时间跨度匹配1秒，容差0.05秒。三个方法共用完全相同输入/标签/样本：透明运动学（常速度预测为基础）、absolute ridge、baseline residual ridge。ridge alpha=1，输入标准化只从train计算；不搜索blend、OOD阈值或超参。两个学习模型保存重载并核对推理时域。

旧D3报告用6 train/6 validation、每集24样本，本轮训练episode数和采样数都变化，不能把两轮数字差异单独归因于新增训练数据。主要比较是本轮相同576个验证样本上的三种方法。

## 接纳、复现和诊断含义

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python scripts/run_d4_rollout.py --split artifacts/acceptance_20261028/development_split_v2.json --output artifacts/d4_rollout_20261029 --samples-per-episode 96 --hash-mib-per-s 16
python -m pytest -q tests/test_d4_rollout.py
```

重跑必须换新output目录。输出protocol在源文件读取和拟合前写入，记录冻结参数、manifest SHA及源码SHA；所有源文件完整SHA/大小匹配后只读加载state，不加载RGB，检查前后mtime/大小不变。读取串行限速16MiB/s，逐文件凭据写verified_reads.jsonl；源PASS或指纹失败即中止，不生成完成报告。

训练使用HDF oracle状态和后向速度，没有把未来行放进输入，但尚不是按可见性门控的live belief训练。记录相机速度只是动作代理，不等于真实命令；偏航输入恒为0。模型训练四个outcome：image_center_error是入框状态二值代理，covariance_trace是遮挡/入框规则派生值，不是像素中心误差或实测、校准的协方差。visible_ge_0_5计数包含未知可见性映射为0.5的可能性，不能一概解释为确认可见帧。报告是原始未裁剪回归误差，不是部署时clipping/blend后的表现，更不是候选反事实后果或跟踪收益。

支持域仅用train每个feature的min/max（1e-8数值容差），分别统计state/action越界。对validation的每个相同state替换八个默认候选，记录各候选越界数和完整state/action特征到最近train样本的标准化欧氏距离。方差接近0的轴以1个原生单位缩放；偏航常零时任何有意义非零候选均越界。边际区间内不等于联合支持，也不等于动作因果支持；距离没有转成部署门控阈值。本轮不调整候选以制造覆盖率。

完整机器结果见 [公开证据](evidence/d4_rollout_20261029.json)。本机模型、冻结协议和逐文件读取账本保存在 `artifacts/d4_rollout_20261029/`；不上传原始HDF或模型内本地路径。公开证据含文件名、seed、SHA、参数和逐集结果，源数据仍需获授权后才能复现实验。

源码SHA记录实际运行时的文件字节，不是跨平台换行规范化摘要。提交后切换main时，本机 `core.autocrlf=true` 将新增runner和rollout_diagnostics.py由LF转换为CRLF；已逐项验证仅这两个文件的原始SHA不同，规范化回LF后与运行指纹一致，其余包源码、hash reader和模型原始SHA一致。原始protocol/report不修改。复现者应区分换行差异和代码差异；禁止将HDF或模型的SHA不一致按文本换行处理。
