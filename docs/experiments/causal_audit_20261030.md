2026-10-30，Asia/Shanghai。用户提供《如何把一个模型改成 Causal（因果）模型》后，对现有数据适配、训练、历史窗口、推理及代理回放逐项核查。文档只作为检查参考，不作为执行命令。

## 实际发现与修复

**仍有一个整段统计量的因果性漏洞，已在本轮修复。** `HDF5Episode.tracking_state()` 曾将 HDF 属性 `minimum_static_clearance_m` 作为每帧 UAV 障碍间距，`closed_loop.py` 又从同一属性初始化代理 UAV。该值不是时间 t 的传感器读数：本机生产端 `run_independent_uav_episode.py` 第 2547 行在采集过程中执行 `minimum_clearance = min(minimum_clearance, clearance)`，第 3512 行在写出元数据时保存该累计最小值。未来时刻可能改变它，进而改变较早的安全过滤、utility 和 Jev 输入。

本轮只读生产端代码，没有修改或启动采集、上传、共享配置或锁。读取的生产端源码 SHA256：`b8268059b824f992ce4650ecfccb28ffdb057d0dbc93a810f4176ffda10f5524`。此为当前本机生产端实现证据，不替代每份历史 HDF 的生产版本溯源。

修复边界：

- HDF 适配器不再把整段最小间距映射到当前状态，也不再在缺失时虚构 10m 间距；没有映射逐帧间距传感器时，用 0 表示未观测的保守边界，并标记 `obstacle_margin_source=unobserved_fail_closed`。
- 代理回放不再覆盖初始状态中的间距为全局最小值；沿用调用方给出的初始状态间距。HDF 初始状态现在为 0。该代理仍没有实时障碍几何更新，不是动态安全测量。
- 没有放宽默认 3m 安全门槛。标准 HDF 在该门槛下所有候选被拒绝是预期行为，不能算作实测碰撞。
- 原 budget CLI 合成测试显式传入零间距阈值，只为测试预算耗尽回退；真实默认配置不改。另有回归测试要求 HDF 未观测间距在默认门槛下拒绝所有候选。

两条漏洞回归测试先在原实现失败（当前状态/selector 输入随全局间距变化），修复后通过。

## 按指南逐项核查

| 检查点 | 当前实现与证据 | 限制 |
| --- | --- | --- |
| 时间卷积、双向 attention/RNN | 当前 rollout 是运动学加线性 ridge，并没有这些时间网络层 | 不能据此认证未来增加的视觉网络 |
| 速度估计 | 后向差分；测试同时覆盖原始 HDF 未来位置扰动和既有差分回归 | 数据源位置本身是否由非因果平滑器生成仍需生产版本审计 |
| 历史窗口 | 只读取当前帧及之前；扰动未来 HDF 后窗口相同 | 历史身份字段仍是模拟/标注来源，不是 RGB ReID |
| 归一化 | 均值与方差只在拟合集计算，推理复用冻结值；改变未来查询行、改变 validation 标签不改变前缀输出或模型参数 | 不是对整个验证视频重新计算统计量；不能混淆离线训练统计与测试序列归一化 |
| 输入/标签 | t 输入，t+5 监督标签，约 1s 预测时域；未来扰动只改变对应标签、不改变 t 之前输入 | 未来标签是合法监督，不是在线可用观测 |
| 整段统计量 | 发现并移除全局最小间距进入状态和代理回放的路径 | 旧的相关安全/选择报告不能当严格因果证据 |
| 遮挡真值 | 已有可见观测→causal estimator 的在线/代理路径有隐藏真值扰动测试 | D4/D5 记录动作训练仍是 HDF oracle 输入，不是完全可见性门控的在线感知训练 |

指南对 GroupNorm/LayerNorm 的建议需要结合张量轴理解：仅更换层名不构成因果性证明，若统计轴跨越未来时间仍会泄漏。本仓库当前没有这些层；不做无关网络替换。

## 对既有结论的影响

- D4 的四个训练目标和四个透明 baseline outcome（可见性、中心代理、距离、协方差代理）不直接使用障碍间距，因此该漏洞本身不推翻其已报告的四维 RMSE；不因此宣布 D4 端到端因果性通过。
- 旧离线选择/安全事件可以受到全局最小间距影响，继续只作历史代理结果，不用来支持在线安全或跟踪收益。新 D5 将无安全候选与未执行的排名诊断明确分列。
- 既有 live belief 探针本来就因缺实测间距/电量而拒绝动作；本次未启动仿真，也没有补成真实跟踪闭环。
- 可见性/协方差标签仍是规则代理，动作仍是相机速度代理；无真实动作反事实覆盖、真实身份交叉仍 NOT_AUDITED，均保留。
