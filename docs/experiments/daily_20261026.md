# 2026-10-26：冻结可复现 episode split

## 目标

完成两周冲刺 D1 的数据划分切片：把现有两个显式 PASS manifest 合并为一个 episode-disjoint 的训练/验证/困难开发集合，并明确当前没有未使用的最终测试集。

## 输入与边界

- 只读取 `artifacts/module_ablation_20261022/pass_manifest.json` 和 `artifacts/occlusion_pass_20261024/pass_manifest_sha256.json`；源 HDF5 保持只读。
- 每个输入 episode 必须是 `validation_status=PASS`；重复路径和非 PASS 条目会在冻结时拒绝。
- 困难 manifest 已用于阈值、rollout 和闭环代理诊断，因此放入 `development_stress`，不冒充 final test。
- 未启动或修改 CarlaAir 采集/上传链，也没有调用 Jev 服务。

## 命令与验收

```powershell
python scripts/freeze_experiment_split.py `
  --baseline-manifest artifacts/module_ablation_20261022/pass_manifest.json `
  --difficult-manifest artifacts/occlusion_pass_20261024/pass_manifest_sha256.json `
  --output artifacts/experiment_split_20261026.json
python -m pytest -q tests/test_freeze_experiment_split.py
python -m compileall -q scripts src
```

结果：`2 passed`，编译检查通过。生成的冻结快照保存在本机被 Git 忽略的 `artifacts/experiment_split_20261026.json`，并记录两个源 manifest 的 SHA-256。

## 当前冻结口径

| split | episode 数 | 用途 |
| --- | ---: | --- |
| train | 6 | 6 个场景族的第一组 seed，用于训练 |
| validation | 6 | 同场景族的第二组 seed，用于选阈值和模型 |
| development_stress | 5 | 遮挡/出框困难回放；只用于开发诊断 |
| final_test | 0 | 暂不可用 |

train/validation/development_stress 按 episode 路径完全不重叠，且全部是 PASS。当前 17 个 episode 都已经被开发实验或阈值探索使用，不能把其中任何一个重新命名为独立最终测试集。D1 计划的 30–60 个独立 episode 目标尚未满足，最终测试必须在新的、未用于调参的 PASS 数据审核后冻结。
