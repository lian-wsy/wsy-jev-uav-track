## 方法与预算

比较既有反馈跟随器、透明+utility、residual+utility、同residual+Mock、同residual+真实Jev。共享感知、候选动作及顺序、硬约束、低层控制、初始条件、仿真时长和决策频率。所有fallback、超时、过期响应、提前结束都入账；报告selector原始结果和最终执行动作。无安全门控只允许离线压力测试。

预测 horizon固定1秒，高层目标1Hz、低层目标20Hz是未来live待验证契约；原HDF图像5Hz/state25Hz是采样率，不等于执行控制率。当前代理批处理每0.2秒重规划，另行标记，不充当1Hz真实结果。Jev调用遵守预算报告，不通过更多调用改变一方的计算预算。

## 主指标

| 指标 | 定义与缺失处理 |
| --- | --- |
| 可见率 | 每episode有效观测中正确目标可见比例，再episode等权；提前终止的live轨迹按预定时间网格补失败，不能只统计存活部分 |
| 固定窗重捕获 | 预设遮挡/出框起点为t0，观察窗10秒；连续正确跟踪至少0.5秒才确认，耗时为确认时刻减t0；失败或提前终止计10秒；另报恢复率和成功事件耗时 |
| 事件资格 | 必须由方法无关场景协议提供完整10秒reference窗；不满足者预先排除并报数。按时间选非重叠窗；方法自行造成丢失单独记录，不混入主事件分母 |
| 身份 | 真实多目标交叉、可见检测关联下报告正确ID比率/切换；单actor、缺真实标注或oracle关联均不得当真实身份保持验收 |
| 安全 | 真实碰撞传感器、场景几何最小距离和每运行事件率；预测near-miss另列，不能替代碰撞 |
| 延迟/成本 | 端到端wall-time p50/p95、请求次数（含失败/重试）、超时、动作到期、fallback、实际usage和费用 |

样本时间不能倒退/重复/非有限；不能用两个稀疏成功点推断中间连续成功。离线实现 `event_metrics.py` 默认连续样本最大间隔0.25秒，匹配5Hz回放。Live 20Hz观察可采用0.075秒上限，必须在最终test前固定；这仍是采样意义上的连续，不声称证明帧间无丢失。

`evaluate_fixed_event_replay.py` 从源标注生成方法无关事件，对比同一episode集合；`score_reacquisition` 将提前结束/缺少恢复观测计失败。现有5个development episode只有3个完整可评事件、另外3个尾部不足窗，不能借旧“成功事件均值”充当该主指标。该工具不对最终测试调参，当前只是指标回归和开发诊断。

## 统计与判定

按独立episode/seed成对bootstrap计算95%区间，保持同seed的派生片段在同一组；不得把帧视为独立样本。完整报告展示全部seed、失败、样本量和不支持的条件，缺事件/缺标注记 `NOT_AUDITED`，不填100%。n=3事件的开发诊断不给泛化显著性结论。

沿用冲刺工程门槛：困难episode等权可见率相对冻结最强非Jev基线提升至少5个百分点，受限重捕获时间降低至少20%，普通跟踪可见率退化不超过2个百分点；同时报告区间与安全事件。区间跨零或安全变差不能宣布达标。Jev贡献必须在同rollout、同预算下独立比较utility。

当前可运行的是代理固定窗重捕获与已有代理统计；独立仿真碰撞、统一低层执行/延迟、成对bootstrap正式矩阵及完整视觉关联尚未验收。指标协议冻结不等于这些未来运行已完成。
