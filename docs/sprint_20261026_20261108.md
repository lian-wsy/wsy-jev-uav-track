## 方法假设与范围

核心假设：由短时历史估计目标运动和不确定性，学习动作条件残差及其可信范围，在遮挡/丢失时生成可重捕获候选，再由 Jev 选择，可在统一安全约束下改善跟踪。暂用描述性名称“历史与不确定性感知的残差 rollout + Jev 选择”，新颖性待相关工作核对，不宣称已构成论文贡献。

两周内优先做小型可解释预测器/轻量 ensemble，不从零训练大型视觉或世界模型。Jev 作为外部选择器，不称为自训练模型。若提升主要来自 rollout 而非 Jev，论文必须这样归因；不能将 API 接通本身当创新。

先跑 oracle-state 控制诊断，再接所有方法共享的可见目标检测/跟踪输入。oracle 不可把遮挡中的真值位置、身份、未来轨迹送入方法；隐藏真值仅用于评估。若只能完成 oracle-state 实验，交付明确限定为控制原型，不能声称端到端视觉跟踪。

## 公平对照与提升门槛

最小主对照：追踪误差反馈 PID/既有可复现跟随器；透明 rollout+utility；residual rollout+utility；同 residual+Mock；同 residual+真实 Jev。共享感知、候选库、安全阈值、控制器、初始条件和事件触发频率。报告最终系统动作和 selector 原始选择，防止 fallback 掩盖真实贡献。相关工作至少核对一个可复现且适用的已发表 active tracking 方法；若两周内没复现，注明缺口，不宣称优于 SOTA。

主要效应目标（工程验收值，不是文献标准）：相对 validation 选定并冻结的最强非 Jev 基线，困难场景 episode 等权可见率提高 ≥5 个百分点，同时受限重捕获时间降低 ≥20%，正常跟踪可见率退化 ≤2 个百分点。报告成对 95% 区间；若区间跨零或只在个别种子获益，结论为不确定，而非已证明提升。Jev 独立贡献另比较同 rollout+utility，不混合归因。

重捕获以事件开始到连续至少 0.5 秒正确跟踪为恢复，10 秒固定观察窗；超过窗或未恢复计失败、受限时长计 10 秒，同时给恢复率和成功事件时间，不能仅平均成功例。仅选择具备完整观察窗的事件（由场景协议预定，不依赖方法）；提前终止以失败计入。损失事件按预设遮挡/出框窗口配对，方法自行造成的丢失另统计。

安全用仿真器碰撞传感器和场景几何的真实最小间距，报告每运行碰撞率/近失率，现有预测 near-miss 只作为辅助。验收要求无新增可归因严重碰撞且碰撞率点估计不升，同时提供区间；小样本零事件不等于证明安全。身份保持仅对可见检测关联和真实多目标交叉评价，单 actor 不报“100%交叉保持”。延迟记录 p50/p95、超时与动作过期率，高层暂以 1 Hz 为目标、内层 20 Hz；D6 根据实测调整且在最终 test 前冻结。

## 数据与实验边界

- 现有源 HDF5 只读且必须 PASS；新分支数据只写本任务独立输出，审核通过才进入训练。按 scenario/seed 分组去重，复制文件不能跨 split，连续帧不能伪装独立样本。
- D8 的新动作数据只来自 train/development 场景，不从 final test 回流训练。所有阈值只用 validation 选，final test 若暴露问题，修复后需新的未使用 test 或标记探索性。
- 真实仿真需要独立实例或明确移交给本任务的空闲环境。不能 reset/tick/load_world/改设置或停止其他采集/上传控制链；端口暂时空闲不代表释放。核验所有权、共享配置隔离、设备余量后才运行，不能以本计划授权改动原任务。
- 仅操作本任务创建的进程和输出，不运行通用 Start/StopCarlaAir 脚本，不接真实飞行。无独立环境时继续 adapter/单元测试并记录 BLOCKED，不擅自借用正在采集的实例。
- Jev key 仅来自环境变量，不落文件/日志/Git。已有授权只涵盖小规模试验；准备阶段单批最多 8 次、总计最多 32 次请求（重试也计数），预算耗尽/无 key 时用 Mock 并标记。正式矩阵费用估算形成可审核结果后，扩大付费调用需用户明确预算。Mock 不能冒充真实 Jev。
